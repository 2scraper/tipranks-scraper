One thing worth saying plainly

Bot protection

Fastly + Cloudflare, and an unrendered reCAPTCHA. Two edge layers sit in front of tipranks.com, confirmed from real response headers: Fastly (caching — the page up to 24h, the JSON payload up to 5 minutes) and Cloudflare (a bot-management fingerprinting script on every page view). Google reCAPTCHA's script is also loaded on the page, present but never auto-rendered. Neither challenged the original research session, but a later audit observed a real one: an HTTP 403 Cloudflare JS challenge ("Just a moment...") on the page navigation, in a local headless Playwright run, after an earlier run had already completed successfully — behavior-triggered, not a first-request block. The scraper reports that state as exit 3 and the daily live canary treats it as unavailable rather than leaving a misleading green badge. No confirmed CAPTCHA widget has ever been found on this site — --proxy/--cdp-endpoint (a 2Captcha toolkit, opt-in, added after this block was observed) are this project's own evidence-backed mitigations, not a confirmed bypass. See tipranks_parser.py's module docstring for the full detail.

Get started

# clone and install — no .env, no credentials needed for a normal run
git clone https://github.com/2scraper/tipranks-scraper.git
cd tipranks-scraper && pip install -r requirements-playwright.txt && playwright install chromium

# one ticker, or several
python3 playwright_scraper.py --ticker AAPL --ticker MSFT --format json --out results.json
